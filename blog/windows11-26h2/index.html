Windows 11の2026年版「26H2」が全ての対象PCに。24H2のままのパソコンは更新が止まっています

Windows更新PC運用

2026年9月29日、Windows 11の年に一度の大きな更新「バージョン26H2」（Windows 11 2026 Update）が公開されました。そして10月28日、Microsoftは「対象となるすべてのパソコンに届くようになった」と案内を更新しています。

「大きな更新」と聞くと、画面がガラッと変わるイメージがあるかもしれません。でも26H2は、そういう更新ではありません。中身の多くは、すでに月ごとの更新で少しずつ届いています。 26H2の本当の意味は、期限の延長です。24H2から入れれば、Home・Proの更新期限は2028年10月10日まで延びます。

そして、ひとつ期限が過ぎています。24H2のHome・Proは、2026年10月13日で更新が終わりました。 まだ24H2のままのパソコンは、11月10日の月例更新も届いていません。

先に結論だけ

  • 26H2は「OSの入れ替え」ではありません。24H2や25H2のパソコンには、小さな有効化パッケージとして届き、再起動1回程度で切り替わります。
  • 24H2のHome・Proは2026年10月13日で更新終了。そのままでは、セキュリティの修正が届かなくなっています。
  • 26H2に入れると、Home・Proの更新期限は2028年10月10日まで延びます。25H2のままなら2027年10月12日までです。
  • 確認は「設定 → システム → バージョン情報」。バージョン26H2・OSビルド26300なら、今の最新版です。
  • Windows Updateに26H2が出てこない場合は、しばらく待ってください。互換性の問題があるパソコンは、Microsoft側が意図的に止めています。

26H2って、そもそも何？

Windows 11は、年に一度、バージョンがひとつ進みます。2024年が24H2、2025年が25H2、そして2026年が26H2です。

たとえるなら、建物の管理契約の更新に近いものです。建物そのものは同じ、住んでいる部屋も同じ。変わるのは「補修部品が届く期間」です。26H2にすると、その期間が2028年10月まで延びます。

「新しい機能がたくさん入る更新」ではない、というのが今回のポイントです。Microsoft自身、「26H2、25H2、24H2は同じ土台を共有しており、新機能の多くは月例の更新で既に届いている」と説明しています。26H2は、届いていた機能をまとめて有効化し、サポートの時計をリセットする更新です。

だから、26H2を入れたからといって、急に使い方が変わることはありません。スタートメニューの並び替えや、タスクバーの位置を変えられるようになるなど、見た目の小さな変化はありますが、基本の操作は同じです。

バージョンごとの「更新が届く期限」

バージョン 公開日 Home・Proの期限 Enterprise・Educationの期限
24H2 2024年10月1日 2026年10月13日で終了 2027年10月12日
25H2 2025年9月30日 2027年10月12日 2028年10月10日
26H2 2026年9月29日 2028年10月10日 2029年10月9日

期限は「その日を過ぎると、セキュリティの修正が届かなくなる」という意味です。パソコンが動かなくなるわけではありません。ただ、穴が見つかっても塞がれなくなります。

なお、26H1という別バージョンもあります。2026年初めから出荷された新しいデバイス専用のもので、既存のパソコンから移行するものではありません。「26H1」と表示されるパソコンは、そのまま使い続けて大丈夫です。

24H2のままが、一番の注意点

HomeやProを使っている会社のパソコンで、まだ24H2のままなら、10月13日を境にセキュリティの修正が止まっています。11月10日の月例更新（KB5132061）も、24H2のHome・Proには届きません。

法人向けのEnterprise・Education版の24H2は、2027年10月12日まで更新が届きます。会社のパソコンがどちらか分からない場合は、「設定 → システム → バージョン情報」の「エディション」を見てください。HomeやProと書かれていれば、Home・Proの期限が適用されます。

25H2のままのパソコンは、2027年10月12日まで更新が届くので、急ぐ必要はありません。ただ、26H2にしておけば、期限は2028年10月10日まで延びます。

自分のパソコンは、何を見ればよいか

確認する場所は1か所だけです。

  1. 「設定」を開く
  2. 「システム」→「バージョン情報」を開く
  3. 「バージョン」と「OSビルド」を見る

ビルド番号で、バージョンが分かります。

OSビルド バージョン
26100 24H2
26200 25H2
26300 26H2

「26H2」と表示されていれば、今の最新版です。「24H2」と出たら、切り替えの検討を。「25H2」なら、来年の10月まで余裕があります。

26H2を入れる手順

24H2か25H2のパソコンなら、手順はシンプルです。

  1. 業務データのバックアップを取る（更新の前には、ふだんからあるかどうかを確認）
  2. 「設定」→「Windows Update」を開く
  3. 「最新の更新プログラムが利用可能になったらすぐに入手する」をオンにする
  4. 「更新プログラムのチェック」を押す
  5. 「Windows 11、バージョン26H2」が表示されたら、「ダウンロードとインストール」を選ぶ
  6. インストールが終わったら、再起動まで済ませる

26H2そのものは小さなパッケージなので、ダウンロードと再起動は短時間で済むことがほとんどです。ただし、入れる前の月例更新がたまっている場合は、そちらが先に入ります。

Windows Updateに26H2が出てこない場合は、無理に探さず、しばらく待ってください。Microsoftは、互換性の問題が分かっているパソコンには、意図的に更新を止める仕組み（セーフガードホールド）を使っています。止められているのに、別の方法で無理に入れると、かえって不具合の原因になります。

なお、Windows 10のパソコンは、この手順では26H2にはなりません。Windows 11へのアップグレード自体が別作業です。11月2日の記事で書いたESUの話とあわせて、行き先を決めてください。

入れたあと、気をつけたい2つのこと

USBのヘッドセットやマイクの音が出ない

26H2を入れたあと、一部のUSBオーディオ機器（古い規格のUSB Audio Class 1.0）で、音が出なくなったり、デバイスマネージャーに「このデバイスを開始できません（コード10）」と出たりする不具合がありました。

この不具合は、11月10日の月例更新（KB5132061）で修正されています。26H2を入れたあとは、11月10日の更新まで入っているか確認してください。更新履歴にKB5132061があれば、修正は入っています。

11月の更新が、うまく入らないことがある

11月11日に、Microsoftは11月のセキュリティ更新自体について、「一部のデバイスでインストールに失敗することがある」という既知の問題を追加しました。自動修復が用意されており、11月11日午前10時（太平洋時間）から24〜48時間で走ると案内されています。

インストールに失敗した場合は、何度も手動で入れ直さず、1〜2日様子を見てください。エラーの番号（0x80070306など）が出たまま繰り返す場合は、更新を消したり戻したりする前に、まず何が起きたかを控えてください。

今回をきっかけに決めておきたいこと

  1. パソコンの台帳に、バージョンを書き加える。 機種、OSのバージョン、ビルド番号を1台ごとに記録します。「何台が24H2のままか分からない」状態が、いちばん判断を遅らせます。
  2. 年次更新の確認を、毎年10月の定例にする。 Windows 11の年次更新は、毎年秋に出ます。10月にバージョンを確認する習慣があれば、期限切れに気づかず使い続けることがなくなります。
  3. Windows 10のままのパソコンの行き先を決める。 26H2の話とは別ですが、Windows 10の延長更新（ESU）も期限があります。11月2日の記事の手順で、残っている台数を確認してください。

Alpha Scriptでは、ホームページの更新だけでなく、こうした「社内のパソコンがどういう状態か」の確認も、運用の一部として一緒に見ています。自分のパソコンのバージョンが分からないときは、機種名とバージョン情報の画面が分かれば、公式情報と照らして整理できます。
