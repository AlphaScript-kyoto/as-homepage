Windows 10のままの会社のパソコン、10月14日で何が変わったか。担当者がまず確認すること

セキュリティWindowsPC運用

2026年10月14日、ひとつの区切りが過ぎました。法人向けのWindows 10延長セキュリティ更新（ESU）が2年目に入り、料金が初年度の倍になったのです。

パソコンが動かなくなるわけではありません。変わるのは、セキュリティの修正が届くかどうかと、その料金です。

そして厄介なのは、個人向けと法人向けで、名前が同じなのに中身が違うこと。「うちも無料で延びたはず」という思い込みが、いちばん危ないパターンです。

先に結論だけ

  • Windows 10の通常サポートは、2025年10月14日に終わっています。パソコンは動きますが、通常のセキュリティ更新は届きません。
  • 個人向けのESUは2027年10月12日まで続きます。ただし、会社の管理下にあるパソコンには使えません。
  • 法人向けESUは、1台あたり年単位の有料ライセンスです。2年目は122米ドル、2年目から入る場合は1年目分もあわせて183米ドルになります。
  • ESUで届くのは、Microsoftが「緊急」「重要」と分類したセキュリティ更新だけです。新機能や技術サポートは含まれません。
  • まず確認するのは3つだけです。台数、管理の形態、Windows 11に対応できるかどうか。

OSは、建物でいえば土台です。サポート終了とは、土台の補修部品がメーカーから届かなくなること。ESUは、建て替えまでのあいだ応急の補強だけを頼む契約のようなものです。なお対象は、Windows 10の最終版バージョン22H2だけです。

個人向けと法人向けは、名前は同じで別物

個人向けESU 法人向けESU
対象 個人で使うWindows 10 バージョン22H2 組織に属するパソコン。ボリュームライセンス等で購入
期限 2027年10月12日まで 最大3年間。2年目は2027年10月12日まで、3年目（最終）は2028年10月10日まで
料金 無料登録、Microsoft Rewards 1,000ポイント、30米ドルの1回購入のいずれか。1ライセンスで最大10台 1台あたり年単位。1年目61米ドル、2年目122米ドル、3年目244米ドル。途中参加は前年分も支払う
含まれないもの 新機能、セキュリティ以外の修正、技術サポート 新機能、セキュリティ以外の修正、技術サポート

分かれ目は「誰がそのパソコンを管理しているか」です。ドメインやMicrosoft Entraに参加しているパソコン、管理ツールに登録されているパソコンは、個人向けの対象外になります。

会社としての管理をかけていない個人事業主のパソコンなら、個人向けが使えることもあります。分からなければ、管理を頼んでいる業者や販売店に聞いてください。

なお、WordやExcelなどMicrosoft 365アプリの更新は2028年10月10日まで続きますが、OSとは別の話です。「Officeは更新が来るから大丈夫」と見落とさないでください。

料金は、買い替えと比べる段階に入った

1台あたり（米ドル） 10台の場合の目安（米ドル）
1年目（〜2026年10月13日） 61 610
2年目（2026年10月14日〜2027年10月12日） 122 1,220
3年目（〜2028年10月10日） 244 2,440
2年目から初めて入る場合（1年目分を含む） 183 1,830

これは米ドル表示のリスト価格で、実際の請求額は契約形態や通貨で変わります。IntuneやWindows Autopatchで管理している場合は割引価格もあります。見積もりは販売店に確認してください。

考え方はシンプルです。ESUは移行までの期間を買うもの。1台だけ残すなら有効ですが、全台を3年目まで延ばすなら買い替えのほうが安いことがほとんどです。

自分の会社は、どれに当てはまるか

1. Windows 10のままの台数を数える

会社で使っているパソコンのうち、Windows 10のままのものが何台あるか。ESUの料金は台数で決まるため、ここがすべての計算の出発点です。

2. 管理の形態を確認する

ドメインやMicrosoft Entraに参加しているか、管理ツールに登録されているか。ここが「個人向けESUが使えるかどうか」の分かれ目です。

会社管理のパソコンは、法人向けESUか、Windows 11への移行か、買い替えかの3択になります。

3. Windows 11に対応できるかを確認する

Microsoftの「PC 正常性チェック」アプリで確認できます。要件の中心は、対応CPU、メモリ4GB以上、ストレージ64GB以上、TPM 2.0、セキュアブートです。

「TPMが無効になっているだけ」で弾かれていることもあり、その場合は設定画面（UEFI）で有効にできることがあります。分からなければ、無理に設定を変えず、購入先や保守先に相談してください。

3つの進み方

進み方1：Windows 11へ無料でアップグレードする

要件を満たしているパソコンは、Windows Updateから無料でアップグレードできます。最もすっきりした解決策です。

事前に、バックアップと、業務ソフトや周辺機器がWindows 11で動くことの確認だけは忘れずに。古い会計ソフトや専用機器は、メーカーの対応情報を見てください。

進み方2：法人向けESUの2年目を買って、移行期間を確保する

専用ソフトや機器の都合ですぐに移行できないパソコンは、ESUの2年目を買って時間を確保します。

大事なのは、購入と同時に移行や買い替えの期限を決めること。「2027年10月12日までにどうするか」をカレンダーに入れてください。3年目はさらに倍額になるため、なし崩しに延ばすほど負担が増えます。

進み方3：買い替える

Windows 11の要件を満たしていないパソコンや、動作が重くなっているパソコンは、買い替えが現実的です。

部品価格が上がっている時期なので、見積もりは複数社で比較を。処分前のデータ消去も確実に行ってください。

移行・買い替えの前に、チェックリスト

  • [ ] 業務データと、デスクトップやドキュメントに入っているファイルのバックアップを取ったか
  • [ ] メール、会計ソフト、専用ソフトのログイン情報と設定を控えたか
  • [ ] 業務で使うソフトとプリンターなどの周辺機器が、Windows 11で動くか確認したか
  • [ ] Windows 10のまま残すパソコンがある場合、ESUの対象と期限を台帳に記録したか
  • [ ] 古いパソコンを処分する場合、データ消去の方法を決めたか
  • [ ] 移行の作業日を、業務の閑散期に置けたか

今回をきっかけに決めておきたいこと

  1. パソコンの台帳を作る。 OSのバージョン、管理形態、ESUの期限、買い替え予定を1台ごとに記録します。「何台残っているか分からない」状態が、いちばん判断を遅らせます。
  2. 法人向けESUの最終期限（2028年10月10日）をカレンダーに入れる。 そこまでに、すべてのWindows 10パソコンの行き先を決めておきます。
  3. 個人向けの延長を、会社のパソコンに流用しない。 名前が同じでも、対象と料金が違います。

Alpha Scriptでは、ホームページの更新だけでなく、こうした「社内のパソコンがどういう状態か」の確認も、運用の一部として一緒に見ています。台帳の作り方や移行の順番で迷うときは、台数と管理形態が分かれば、公式情報と照らして整理できます。
